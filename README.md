# Учебный прототип кредитного скоринга

Веб-интерфейс и Flask API для изучения классификации кредитных записей. Скрипт обучения сравнивает дерево решений и случайный лес. Данные [South German Credit](https://archive.ics.uci.edu/dataset/573/south+german+credit) опубликованы UCI по CC BY 4.0. Выборка историческая и стратифицированная. Результат предназначен для учебной демонстрации.

## Запуск

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python train.py
python -m flask --app app run
```

Откройте http://127.0.0.1:5000. Обучение создаёт локальный `model.joblib`. Загружайте только артефакт, который сгенерировали в доверенной среде, поскольку joblib десериализует Python-объекты.

## Контракт прогноза

`POST /predict` принимает JSON-объект со всеми числовыми признаками формы и необязательным `threshold` от 0 до 1. Ответ содержит `proba_bad`, `threshold` и демонстрационное решение. При `P(bad) >= threshold` ответ содержит `REJECT`, иначе `APPROVE`. Для отсутствующего признака, нечислового значения, выхода за диапазон данных или некорректного порога возвращается 400.

В кодировке источника `kredit=0` — bad и `kredit=1` — good. API находит колонку вероятностей по сохранённому отображению и `classes_`. Старый обработчик принимал вероятность класса 1 за риск. Исторические F1, Recall и Precision в артефакте обучения рассчитаны для good. Порог не калиброван для реального кредитного процесса.
